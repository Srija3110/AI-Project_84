## Setup
The following instructions should be followed.We have used Jupyter notebook for our main code file
code has been tested on python version 3.14.6(on Mac,Windows)
Open a terminal and type the following in order
```text
git clone https://github.com/Srija3110/AI-Project_84.git
```
```text
cd AI-Project_84
```
```text
python -m venv venv
```
For Windows
```text
venv\Scripts\activate
```
For MacOS/Linux
```text
source venv/bin/activate
```
then install the requirements
```text
python -m pip install -r requirements.txt
```
The above is the setup process for the code.

## How to run
1. In the active (venv) terminal, run:
```text
python -m notebook
```
2. On the browser page, open the src folder and click DateWise_Submission_Organized.ipynb
3. In the top menu, click Kernel, then choose Restart & Run All Cells.
4. Wait for execution to finish. The final scores and charts will appear at the bottom.
